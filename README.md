### ⚡ What I Do & Engineering Focus

```ascii
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     🤖 AI ENGINEER      │   📱 MOBILE (AND/FLT)   │    💍 BLE & WEARABLES   │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Agentic Workflows     │ • Jetpack Compose & MVI │ • Smart Ring Protocols  │
│ • LLMs & Prompt Tuning  │ • Flutter Cross-Platform│ • Live Bluetooth Telemetry│
│ • Multimodal AI Engines │ • Kotlin Native Coroutines│ • Device State Sync   │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

- 🤖 **AI Engineering & LLMs:** Designing automated agentic pipelines, prompt architectures, and local on-device / cloud ML integrations.
- 📱 **Mobile Multiplatform (Android / iOS / Flutter):** Building high-performance native apps with **Kotlin / Jetpack Compose** as well as cross-platform mobile apps using **Flutter & Dart**.
- 💍 **Smart Hardware & BLE:** Connecting mobile applications to real-time wearable devices, smart rings, and IoT hardware with Bluetooth Low Energy (GATT & RFCOMM).
- ⚙️ **Modern Architecture:** MVI/MVVM, Clean Architecture, Room DB, Firebase, and reactive data flow using Kotlin Flow and Coroutines.
